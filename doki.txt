Ты — fullstack разработчик. Создай полноценное веб-приложение GreenWind AI для хакатона. Приложение анализирует карту Бишкека и рекомендует места для строительства парков и мини-садов.

=== ЦЕЛЬ ПРОЕКТА ===
Пользователь открывает веб-приложение, видит карту Бишкека и список районов слева. Система анализирует районы по Green Score и показывает, где в городе больше всего не хватает зелени. На карте отображаются проблемные зоны и рекомендованные места для новых парков.

3. Алгоритм расчёта Green Score:

def calculate_green_score(district):
    green_ratio = district.green_area_m2 / (district.area_km2 * 1_000_000)
    distance_penalty = min(district.avg_distance_to_park_m / 2000, 1.0)

    if district.green_area_m2 > 0:
        pop_load = min(district.population / district.green_area_m2, 1.0)
    else:
        pop_load = 1.0

    score = (
        green_ratio * 40 +
        (1 - distance_penalty) * 30 +
        (1 - district.building_density) * 15 +
        (1 - pop_load) * 15
    )

    return round(max(0, min(100, score * 100)), 1)

def get_level(score):
    if score < 30: return "CRITICAL"
    if score < 50: return "LOW"
    if score < 70: return "MEDIUM"
    return "HIGH"

def get_recommendation(district, score):
    if score < 30:
        return "Критический дефицит зелени. Нужен парк площадью минимум 2 га."
    if score < 50:
        return "Недостаточно зелени. Рекомендуется 2-3 pocket park по 0.5 га."
    if score < 70:
        return "Средний уровень. Добавить мини-сады вдоль улиц."
    return "Хороший уровень озеленения."

4. API эндпоинты:

GET /api/districts
→ список всех районов с green_score, level, lat, lon, polygon_coords

GET /api/districts/{id}
→ детальная информация по району

GET /api/recommendations
→ топ рекомендаций по всем районам, сортировка по приоритету

GET /api/recommendations/{district_id}
→ рекомендации для конкретного района

POST /api/recalculate
→ пересчитать все Green Score и обновить БД
